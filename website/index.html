Acknowledgments & Open Source Projects
🤖
AI-Assisted Development: This project was made mostly with AI, mixing and matching open-source tools and libraries for simple tasks.
🔒
100% Local Processing: All segmentation, spell checking, and normalization processes run entirely client-side in your browser memory. No text or input data is ever sent to any remote server or external API.

claws-ts is built on the research, tools, and open-source contributions of these foundational projects:

CLA-WS (claws)
Model Architecture
By Socret360
The original Graph Neural Network (GNN) and TFLite model architecture for fast and accurate Khmer word segmentation.
GitHub Repository
betterkhmer
Normalization
By SIL Global
Fast, deterministic Khmer Unicode reordering algorithm that corrects vowel and subscript ordering according to Khmer orthography without regular expressions.
GitHub Repository
TensorFlow.js & TFLite WASM
ML Runtime
By Google / TensorFlow Team
Hardware-accelerated client-side machine learning engine supporting WebGL GPU acceleration and SIMD/XNNPACK WebAssembly execution in the browser.
tensorflow.org/js
Chuon Nath Dictionary & RAC Corpus
Lexicon & Dictionary
By Samdech Prah Sangha Raja Chuon Nath / Royal Academy of Cambodia
Khmer dictionary vocabulary, word frequency distributions, and spelling standards powering the spell check and prefix-tree suggestion ranking.
